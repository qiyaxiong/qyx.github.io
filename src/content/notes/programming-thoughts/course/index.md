原课程由 B 站 UP 主 [老赵Net](https://space.bilibili.com/454418022) 发布。这套页面严格保持 P1–P46 的顺序，但不照抄口述内容；每一讲都会补上原视频之外的四个层次：问题背景、可运行示例、模式代价和迁移练习。

## 对应原则

- B 站 `Pn` 与本站 `Pn` 一一对应；
- 原合集重复或跳号的课名会原样保留在视频卡片中，站内标题使用统一编号；
- 示例围绕真实工程变化设计，不使用只有 `Cat/Dog` 的玩具类图；
- HTML 关系图先给直觉，代码负责验证，文字解释适用边界；
- 每篇都回答“什么时候不用”，避免为了模式而模式。

## 怎样完成一讲

```text
1. 用一句话说出变化轴
2. 找到原设计中被迫一起修改的代码
3. 画出重构前后的依赖方向
4. 运行或手推示例
5. 写下新设计引入的复杂度
```

能说出模式名不算学会；能在代码评审中解释“为什么这个边界更稳定”，才算真正掌握。
